# JavaScript Fundamentals Assignment

## **Instructions**
- Write your answers in a `.js` file.
- Use comments (`//`) to explain your code.
- Run and test your code to ensure it works as expected.

---

## **Part 1: Variables and Data Types**
### **Task 1: Declare and Initialize Variables**
1. Declare a variable `name` and assign it your full name.
2. Declare a constant `birthYear` and assign it your birth year.
3. Declare a variable `isStudent` and assign it a boolean value (`true` or `false`).
4. Declare an `array` named `hobbies` and add at least three hobbies as string values.
5. Create an object `person` with the properties: `name`, `age`, and `city`.

### **Task 2: Data Type Verification**
Write a program that:
- Prints the type of each variable declared in **Task 1** using `typeof`.

---

## **Part 2: Expressions, Statements, and Operators**
### **Task 3: Mathematical Expressions**
Write a program that:
1. Declares two numbers `a` and `b`.
2. Performs the following operations and logs the results:
   - Addition
   - Subtraction
   - Multiplication
   - Division
   - Modulus
   - Exponentiation

### **Task 4: Comparison and Logical Operators**
Write a program that:
1. Compares two numbers using `>`, `<`, `>=`, `<=`, `==`, and `===`.
2. Uses logical operators (`&&`, `||`, `!`) in an expression and prints the result.

---

## **Part 3: Functions**
### **Task 5: Function Basics**
1. Write a function `greet(name)` that returns `"Hello, [name]!"`.
2. Write a function `calculateArea(length, width)` that returns the area of a rectangle.

### **Task 6: Function with Conditions**
1. Write a function `isEven(number)` that returns `true` if the number is even, otherwise `false`.
2. Write a function `gradeScore(score)` that:
   - Returns `"A"` for scores **90 and above**.
   - Returns `"B"` for scores **80 - 89**.
   - Returns `"C"` for scores **70 - 79**.
   - Returns `"D"` for scores **60 - 69**.
   - Returns `"F"` for scores **below 60**.

---

## **Bonus Challenge**
- Write a function `reverseString(str)` that takes a string and returns it reversed. *(Example: `"hello"` → `"olleh"`)*
- Write a function `factorial(n)` that returns the factorial of a number.
